# FounderOS Specifications

This folder contains the FounderOS / Paperclip adaptation specifications and audit documents.

- [`spec.md`](./spec.md) — primary architecture and operating-model specification.
- [`adaptations_spec.md`](./adaptations_spec.md) — remaining implementation specification and business-application adaptations.
- [`NATIVE_PAPERCLIP_OPERATING_MODEL.md`](./NATIVE_PAPERCLIP_OPERATING_MODEL.md) — normative mapping of FounderOS onto native Paperclip companies, goals, projects, issues, agents, approvals, activity, budgets, and UI.
- [`ADAPTATION_OVERVIEW.md`](./ADAPTATION_OVERVIEW.md) — implementation completeness audit and gap overview.

These documents are companions and should be read together. `spec.md` defines the target architecture; `adaptations_spec.md` defines the remaining implementation work; the native operating-model document constrains FounderOS to Paperclip's visible first-class organizational primitives; and the overview records implementation status at the time of its audit.
